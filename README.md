# Emrys Godwin — Marketing Portfolio

A responsive personal portfolio website for Emrys Godwin, Digital Marketing & E-commerce Specialist.

## Services featured
- Google Ads (Search, Shopping, Performance Max)
- Microsoft Ads
- Meta Ads
- Shopify and e-commerce support
- Google Merchant Center and product feeds
- Conversion tracking and analytics

## Deploy
This is a static website. It can be deployed directly to Vercel with no build step.
